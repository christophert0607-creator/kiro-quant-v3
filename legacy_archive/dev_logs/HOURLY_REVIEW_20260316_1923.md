### Root Cause Analysis

**Primary Issue: Feature Mismatch Between Model and WFA Selection**

The system crashed with:
```
ValueError: Missing required features for inference: ['WILLR_14']
```

**Technical Details:**
1. **Model Training**: The model (`global_state_v4_1_best.pth`) was trained with 28 features including `WILLR_14`
2. **WFA Feature Selection**: `alpha_engine.select_features()` performs correlation-based feature selection, selecting top-k factors
3. **Mismatch**: When `WILLR_14` isn't in the top-k correlated features, it's excluded from `wfa_frame`
4. **DataPreparer Fit**: The symbol-specific preparer is fitted with only the selected features
5. **Inference Failure**: When `predict()` runs, it checks if model features exist in the data preparer's features - fails because WILLR_14 is missing

**Evidence from logs:**
- `Input dim drift detected: model=22 new=24` - shows feature count mismatch
- Model expects 22 features (trained), but new data has 24 (more features selected by WFA)

### Proposed Fixes

**Fix 1: Ensure Model Features Are Always Included**

In `v3_pipeline/core/main_loop.py` around line 228-240, modify to preserve model features:

```python
# Get model's expected features from the checkpoint
model_features = self.model_manager.data_preparer.feature_columns
desired_features = [c for c in wfa_frame.columns if c != "Date"]

# Ensure model features are always included
all_features = list(set(desired_features + model_features))
wfa_frame = wfa_frame.reindex(columns=["Date"] + all_features, fill_value=0.0)
```
